# Raythink

Статичная страница по макету «Главная 2». Откройте `index.html` в браузере.
Ширина фиксирована: 1440 px, высота первого экрана — 800 px.
Фон и шапка — единое исходное изображение. Google Fonts загружаются через интернет.
Библиотеки, плагины, установка зависимостей и сборка не нужны.

Температура обновляется каждые 500 мс в диапазоне 570–630 °C.
Тень предупреждения пульсирует с периодом 1 секунда.
Огоньки расположены ближе друг к другу. Центральный — 28×36,75 px, боковые — 24×32 px.
Огоньки уменьшаются до 80% и возвращаются к исходному размеру с неподвижной нижней границей:
левый — цикл 0,4 с, правый — цикл 0,4 с и задержка 0,2 с, центральный — цикл 0,6 с.

Кнопка открывает почтовое приложение с запросом каталога на адрес из шапки.
Для выдачи PDF замените её `href` в `index.html` на адрес файла каталога.
